# UI、交互与可访问性

## 1. UI 技术基线

客户端必须使用 Flutter `fluent_ui`。Microsoft
[`microsoft/fluentui`](https://github.com/microsoft/fluentui) 是视觉与交互参考；
其 React/Web 包不适用于 Flutter，不得为了名称一致混入 WebView 或第二套前端框架。

规则：

- 优先使用 `NavigationView`、`Button`、`TextBox`、`InfoBar`、`ContentDialog` 等 Fluent 控件。
- 两个以上功能重复的组合模式提取为项目共享 Widget。
- 不修改第三方包源码；差异通过薄封装、Theme 或组合解决。
- 禁止 Material 与 Fluent 控件混搭形成两套视觉。依赖内部使用 Material 图标字体不等于允许使用 Material 页面组件。
- 图标优先使用 Fluent 图标集，不用 emoji 充当功能图标。

## 2. Windows 11 视觉原则

设计关键词：安静、可靠、书卷感、信息清楚。

- 以内容为主，减少装饰性容器和大面积强调色。
- 主色使用克制的青绿色，只用于主要操作、选中态和焦点。
- 背景、卡片、边框使用主题中性色，不硬编码整套颜色。
- 禁止渐变、玻璃噪点、霓虹阴影和无功能的大图背景。
- 同一层级保持统一圆角、边框和间距。
- 阴影只表达浮层或拖放层级，不为普通卡片增加厚重阴影。

默认空间系统使用 4 的倍数：

- 紧密：4、8；
- 控件内部：12；
- 相关区块：16；
- 页面区块：24、32。

正文不小于 14 px 等效逻辑像素；辅助文字不小于 12 px。优先使用 Segoe UI 与系统字体回退。

## 3. 桌面布局

仅支持 Windows，不设计移动端导航。窗口变窄时仍需可用：

- 宽度充足时 `NavigationView` 使用展开侧栏。
- 窄窗口使用紧凑侧栏，而不是移动端底部导航。
- 页面内容设置合理最大宽度，宽屏不把文本无限拉长。
- 网格按可用宽度调整列数；最小卡片宽度不得导致按钮或标题截断。
- 推荐最小窗口尺寸为 960 × 640；更窄时允许滚动，不允许关键操作消失。
- 对话框宽度适合键鼠操作，并确保主要按钮在无需横向滚动的位置。

不得添加 Android/iOS 断点、手势专属流程、底部 Tab Bar 或安全区适配代码。

## 4. 状态与反馈

每个异步区域必须显式覆盖：

- 初次加载：显示进度和正在执行的动作；
- 空状态：说明原因并给出一个主要下一步；
- 成功状态：内容稳定呈现，不反复闪烁；
- 局部更新：保留现有内容并显示轻量进度；
- 失败状态：用户可理解的原因、重试按钮和必要上下文；
- 禁用状态：防止重复提交，同时保持文字可读。

通知规则：

- 可恢复的小错误使用页面内 `InfoBar`。
- 破坏性操作使用确认对话框，按钮明确写“删除书籍”等动作，不只写“确定”。
- 后台任务开始后立即反馈任务已创建，并提供查看入口。
- 日志和底层异常不得直接当作主界面文案。

## 5. 表单与文案

- Label 常驻，不用 placeholder 代替字段名称。
- 必填、格式、范围在提交前后均有一致校验。
- 错误紧邻对应字段；跨字段错误放在表单顶部。
- 保存成功不清空用户仍可能复用的配置。
- 文案使用简体中文、动词开头、避免模糊术语。
- API 密钥默认遮挡，不在日志、错误或截图提示中回显。

## 6. 键盘与焦点

- `Tab` / `Shift+Tab` 顺序与视觉阅读顺序一致。
- 所有主要操作均可仅用键盘完成。
- `Enter` 只在语义明确时触发主要操作；多行文本中不得误提交。
- `Escape` 关闭非破坏性弹窗或返回上一级。
- 对话框打开后焦点进入有效控件，关闭后返回触发元素。
- 焦点指示必须清晰，不通过移除 outline 隐藏。
- 长列表应支持滚轮、Page Up/Down；不要劫持系统级快捷键。

## 7. 可访问性

- 文本与背景常规对比度至少 4.5:1，大文本至少 3:1。
- 不只用颜色表达成功、失败、选中或任务状态。
- 图标按钮必须有 Tooltip 和语义标签。
- 图片提供有意义的语义；纯装饰图片从语义树排除。
- 动画尊重系统减少动态效果设置，时长短且支持被打断。
- 字体放大后允许换行和滚动，不遮挡操作。
- 加载进度、错误和结果数量应可被辅助技术感知。

## 8. UI 评审清单

- [ ] 只使用 `fluent_ui` 与项目共享 Widget。
- [ ] 与 Windows 11 控件、间距和导航模式一致。
- [ ] 亮色、深色、跟随系统主题均可读。
- [ ] 展开与窄窗口布局均可操作。
- [ ] 加载、空、失败、重试与禁用状态齐全。
- [ ] 键盘顺序、焦点返回、Tooltip 和语义标签正确。
- [ ] 长标题、长路径、长错误和 200% 缩放不破版。
- [ ] 没有移动端导航、Web 控件或另一套设计系统。
