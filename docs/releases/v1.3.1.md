## 更新内容

- Windows 客户端新增“本机后端”和“Linux 远程后端”两种连接模式。
- Linux 后端支持使用原生 Python 虚拟环境和 systemd 部署，不需要 Docker。
- 远程连接使用 Bearer Token，Token 保存在 Windows 安全凭据中。
- 新增版本化 FastAPI 接口、远程文件上传下载和服务端导出。
- 隐藏服务器本地路径和敏感配置，远程连接更安全。
- 保留原有本机模式，下载便捷版后仍可直接使用。

## 使用方法

- 普通用户：下载 Windows ZIP，完整解压后运行 `qingjuan.exe`。
- 前后端分离：按 [README](https://github.com/Tavre/QingJuan#linux-后端--windows-客户端) 中的命令部署服务器，
  再在 Windows 应用的“设置 → 后端连接”中填写 FastAPI 地址和连接 Token。

升级前请备份数据。Linux 数据默认位于 `/var/lib/qingjuan`，Windows 数据默认位于 `backend/data/`。
