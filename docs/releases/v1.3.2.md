## 更新内容

- 漫画翻译大幅缩短本地 OCR 与图片回填时间，高置信度 RapidOCR 结果不再等待重复的 Windows OCR。
- 漫画文字样式估算、气泡蒙版和背景取色改用向量化处理，同时保留无 OpenCV 环境的兼容回退。
- 翻译任务新增逐页进度，长章节不再长时间停留在 0%。
- 漫画 OCR 原文与译文改为逐页展示，任务页会增量读取新结果并优先显示最新页面。
- 漫画翻译新增逐页断点；任务失败或应用重启后，会跳过已经完成且校验有效的页面。
- 修复旧翻译链路在大尺寸漫画页上耗时过长、失败后从第一页重复处理的问题。
- 修复 Windows 听书在暂停、停止或退出时可能触发未处理异常并断开调试连接的问题。
- 修复 Windows 发布脚本在 Flutter 编译失败后仍继续打包旧客户端的问题。
