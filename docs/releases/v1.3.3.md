## 更新内容

- 漫画译文改为先在原气泡大小的独立图层中排版，再通过气泡安全蒙版合成，文字与描边不会越过原对话气泡。
- 无法完整放入安全区域的超长译文不再擦除原文或强行溢出，而是保留原图并记录安全跳过诊断。
- 原文清除蒙版新增气泡边界约束，OCR 框或文字膨胀靠近边缘时也不会改动气泡外的画面。
- 漫画渲染缓存版本升级，旧版越界译图会自动失效并按新规则重新生成。
- 顶层工作区切换取消固定 300ms 整页入场等待，导航、侧栏与通用控件动效统一为更短的桌面响应时长。
- 应用外壳只监听当前工作区变化，后端通知、翻译设置和听书设置更新不再触发整套导航与页面重建。
- 实时日志更新改为即时跟随，避免连续轮询期间滚动动画反复叠加；卡片动效会尊重 Windows“减少动态效果”设置。

## 验证结果

- 新增椭圆气泡像素边界回归和超长译文安全降级回归，确保气泡外像素保持不变。
- Python 105 项测试、Flutter 62 项测试、Ruff、Python 字节码编译与 Windows Release 编译通过。
- 完整 Windows 组合包构建及打包后端健康检查通过；正式发布由 Flutter 3.24.3 / Windows 2022 门禁重新构建。
