# 更新内容

- 漫画翻译会根据气泡安全区域估算译文容量；超出容量时，请求翻译模型在保留完整语义、语气、人名和强调信息的前提下精简措辞。
- 精简后仍无法容纳的超长译文会完整绘制到独立图层，再等比缩放到气泡安全蒙版内，不再跳过翻译或保留未翻译原文。
- 安全缩放会寻找气泡蒙版内可用的最大矩形并再次应用蒙版，确保文字和描边不会越过原气泡边界。
- 漫画渲染缓存版本升级，旧版超长译文的安全跳过结果会自动失效并重新生成。
- 新增译文超预算数量、压缩渲染数量和最小缩放比例诊断，便于定位异常页面。

# 验证结果

- 新增超长译文完整渲染像素边界回归，以及模型定长改写回归。
- 132 字极端译文在椭圆气泡中完整渲染，气泡外像素保持不变。
- Python 106 项测试、Flutter 62 项测试、Ruff、Python 字节码编译、Dart 格式化与 Flutter Analyzer 通过。
- 完整 Windows 组合包迁移构建、打包后端健康检查、版本一致性、禁用文件扫描与归档结构验证通过；正式发布由 Flutter 3.24.3 / Windows 2022 门禁重新构建。

本次更新不修改数据库结构、连接配置或本地文件格式。升级前请备份数据；Windows 数据默认位于
`backend/data/`，升级时请整体替换发布目录，不要覆盖已有的 `backend/data/`。
