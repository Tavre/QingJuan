# 更新内容

## Windows 与 Android 共用远端后端

- 新增 Flutter Android 客户端，Windows 与 Android 现在共用同一套界面、阅读偏好和 Linux 后端 API。
- 客户端不再在 Windows 或手机本地启动 Python 后端；书架、书源、任务、正文和阅读进度统一由现有 Linux 服务提供。
- 新增远端地址校验、连接状态管理和安全令牌存储。公网连接要求 HTTPS，HTTP 仅允许可信私有网络地址。
- Android 新增系统文件保存、系统 TTS 声线扫描与试听、音量键阅读以及沉浸式系统栏适配。

## 全新移动阅读器

- 支持左右翻页与上下连续阅读，并提供覆盖、平移、淡入和无动画等分页效果。
- 新增白色、纸张、护眼、淡蓝和夜间配色，以及字号、行距、原文或译文和音量键开关。
- 新增章节目录、章节进度滑杆和快速跳转；当前章显示后会预取相邻章节，滚动模式可直接衔接下一章，缓存命中时不再出现整页等待。
- 顶部、底部和章节目录改为青卷自有的悬浮毛玻璃控制台，设置按字号、纸张配色、阅读方式、翻页动效、排版与按键分区。
- 修复隐藏菜单后正文底部保留空白、沉浸模式切换导致中文顶部被裁切，以及工具栏显隐触发正文排版变化的问题。

## 界面、主题与交互

- 书架、搜索、书源、任务、设置、详情、关于和听书页面统一为暖纸色、陶土强调色与墨色正文体系，深色模式保留一致层级。
- 手机端使用五入口悬浮底部导航；状态栏和系统导航区与页面背景融合，不再出现割裂的顶部色条。
- 重构共享页面、卡片、状态、空页面和反馈组件，补充窄屏、长中文标题、200% 字体缩放和减少动态效果适配。
- 视觉只借鉴成熟阅读产品的通用信息层级，图标组合、配色、圆角、间距、文案和动效参数均采用青卷自有设计。

## 构建、文档与迁移

- README 与开发文档现在同时覆盖 Windows、Android 和 Linux 远端后端，不再描述 Windows 本地后端流程。
- GitHub Actions 在 PR 和主分支上检查 Flutter 分析与测试，并分别构建 Windows 和 Android；发布流程同时产出 Windows 组合包与 Android APK。
- 新增 Android 打包脚本，调整 Windows 构建、打包与发布冒烟脚本，并更新 Issue 与 PR 模板中的跨平台验证项。

- Flutter Analyzer 通过。
- Flutter 78 项测试全部通过，覆盖远端连接、文件导出、阅读缓存与分页、窄屏设置、深色主题、长中文标题和 200% 字体缩放。
- Android Debug APK 构建通过，并在 MuMu Android 15 虚拟机完成安装、系统安全区、中文字体和主题截图验证。

# 升级说明

- 升级后必须配置可访问的 Linux 后端地址；客户端不会回退到本地 Python 进程。
- 本次更新不修改 Linux 后端数据库结构和书籍数据格式。覆盖客户端前仍建议备份服务端数据。
- Android 与 Windows 的界面偏好分别保存在设备本地，书架、任务与阅读进度继续以 Linux 后端为准。
