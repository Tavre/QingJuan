# 更新内容

## Windows 本机与 Linux 远程双后端

- Windows 恢复随安装包提供的本机 FastAPI 后端，可在“本机后端”和“Linux 远程后端”之间显式选择。
- 本机模式固定监听 `127.0.0.1:19453`，无需连接 Token；切换或退出时只回收客户端自己启动的进程树。
- 本机与 Linux 连接档案独立保存。切换模式不会覆盖远程地址或安全存储中的 Token，远程失败也不会隐式回退本机。
- Android 继续保持远程客户端边界，不包含或启动本机 Python 后端。

## Linux 服务管理界面

- 新增随后端同源提供的 React 管理界面，可查看服务概览、书库、任务、书源和连接设备。
- 新增系统诊断、脱敏报告、结构化运行日志、设备封禁、连接 Token 临时显示以及翻译模型自检。
- Linux 安装与更新脚本现在配置随机管理密码、签名会话和连接文件；可通过 `qingjuan-password` 安全修改或重新生成密码。
- 管理密码、连接 Token、模型密钥和会话信息均保持独立存储，默认界面、日志与诊断报告不会回显敏感值。

## 品牌与客户端体验

- 使用新的卷轴 Logo 统一 Flutter 客户端、Windows EXE、Android 启动器、README 和 Linux 管理界面。
- 新增可复现的图标生成脚本，从 `assets/logo.png` 生成 Windows 多尺寸 ICO 与 Android 五档密度资源。
- Flutter 设置页补充当前后端状态、模型自检结果和双连接档案说明。

## 构建与质量

- Windows 发布包重新包含 PyInstaller 单文件后端，并在发布前验证客户端、后端、管理静态资源、版本和敏感文件边界。
- CI 新增 React 管理界面测试与构建、Linux 原生部署冒烟、Windows 组合包冒烟以及 Android/Windows 产物构建。
- 发布流程继续使用固定 Flutter 3.24.3，并校验 `v1.5.0`、`1.5.0+18`、APK、EXE 与 FastAPI 元数据版本一致。

# 升级说明

- 从 V1.4 升级的 Windows 用户会继续保留并默认使用既有 Linux 远程配置；若需要单机使用，请在设置中手动选择“本机后端”。
- Windows 本机数据位于完整解压目录的 `backend/data/`，Linux 数据位于服务器数据目录，两者不会自动同步。
- Linux 用户请使用更新后的 `deploy/linux/update.sh` 升级，并通过 `sudo qingjuan-info` 查看管理地址；旧书库与设置继续保留。
- 建议升级前备份 Windows `backend/data/` 或 Linux `/var/lib/qingjuan`。
