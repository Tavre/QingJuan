# 更新内容

## 站点插件与账号书架

- 将内置站点解析器统一为可声明匹配域名、作品类型、能力与启停状态的插件体系；Windows 本机模式可在客户端管理，Linux 远程后端可在管理界面统一管理。
- 插件配置与 Legado / 阅读 App JSON 书源继续保持独立，启停内置解析器不会改写用户导入的书源。
- 番茄小说与起点中文网支持扫码登录和一键导入当前账号书架；番茄扫码不可用时可改用 Cookie 登录。
- 书架导入会跨分组和分页去重、跳过已有作品、显示任务进度与结果统计，并以“边看边下”模式添加文字作品。单本失败不会回滚已经成功导入的作品。
- 登录 Cookie、会话与站点账号信息只保存在当前后端进程内存中，不写入数据库、普通日志或客户端设置；后端重启后需要重新登录。

## 客户端界面、动效与性能

- Windows 与 Android 继续共享业务能力，但使用明确分离的平台界面：Windows 保持 Fluent 桌面工作区，Android 保持触控优先的移动端导航与安全区适配。
- Windows 新增自绘标题栏、可折叠和拖拽调宽的导航栏、键盘导航快捷键，以及本机插件配置工作区；连接 Linux 远程后端时由服务器管理插件。
- 统一页面切换、路由、按压、选择和阅读器控制层的动效时长与曲线；系统请求减少动态效果时自动切换为零时长。
- 减少无效背景模糊与重复重绘，并为长列表和复杂静态区域增加重绘隔离，提升页面切换、滚动和阅读控制层的流畅度。
- 重新整理书架、搜索、作品详情、阅读器、听书、任务、书源与设置页面的响应式层级，并保留 Windows 本机 / Linux 远程连接边界。

## 后端与管理界面

- FastAPI 新增插件清单、启停、登录、书架预览和异步导入接口，并以插件运行时封装番茄、起点及其他内置站点能力。
- Linux 管理界面新增插件管理页面，支持搜索、状态筛选、详情查看与启停操作；生产静态资源继续随后端同源提供。
- 首次启动会自动创建插件启停设置表并填充默认状态，不删除或重写现有书库、阅读进度、任务和连接配置。
- 补充 Kakuyomu、Yanmaga 等站点解析与回归测试，并增强已有小说、漫画和通用网页解析器的统一调度。

## 发布验证

- 固定 Flutter 3.24.3 下完成 Dart 格式检查、Flutter Analyzer、119 项 Flutter 测试与 Android Release APK 构建。
- Python Ruff、Compileall 与 178 项后端测试通过；React 管理界面 TypeScript 检查、25 项测试和生产静态资源构建通过。
- Android APK 已校验包名 `com.tavre.qingjuan`、`versionName=1.6.0`、`versionCode=20` 与最低 API 26；Windows `1.6.0+20` 组合包已通过客户端、随包后端、版本和敏感文件冒烟检查。
- 正式 Windows 与签名 Android 产物由标签发布工作流使用固定 Flutter 3.24.3 重新构建，并附带 SHA-256 校验文件。

# 升级说明

- V1.6.0 可直接读取 V1.5.0 的 Windows 本机或 Linux 后端数据；建议升级前照常备份数据目录。
- Android 仍只连接 Linux 远程后端，不包含本机 Python；服务器管理员修改插件状态后，连接该服务器的所有客户端共享结果。
- `v1.5.1` 未正式发布，其设置页拆分和管理界面主题调整已合并到本版本。
