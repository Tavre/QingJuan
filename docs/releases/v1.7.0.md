# 更新内容

## Android 阅读产品界面

- Android 非阅读器页面统一为清澈蓝、纯白表面和冷浅灰背景的轻量视觉体系，减少渐变、玻璃模糊和装饰性头图；Windows 继续保持既有 Fluent/Mica 桌面布局与键鼠密度。
- 底部导航固定为“书架、搜索、书源、任务、我的”，“我的”集中设备偏好、服务器连接和关于入口，不引入账号画像或商业内容。
- 新增共享移动端底部面板，统一处理键盘、安全区、返回关闭、焦点与减少动态效果；导入、插件配置和设置等页面不再各自模拟手机弹窗。
- 整理书架、搜索、作品详情、听书、阅读器、任务与设置页面在手机宽度下的层级、触控尺寸和亮暗主题表现。

## 搜索与站点插件

- 搜索页新增“书源、夸克、番茄、起点”引擎选择；切换引擎会清空旧结果，并在结果中保留实际来源，加入书架继续复用现有 URL 导入流程。
- 新增夸克小说匿名公开搜索、作品信息、目录和免费章节解析；付费章节、登录 Cookie、账号书架和试读回退均不接入。
- 拷贝漫画扩展为公开作品搜索、详情、分组目录和漫画页解析，不接入账号能力。
- 新增 COMICORES 公开作品搜索和元数据预览。该站登录后可见的网盘或付费下载资源不解析、不下载，也不伪造成可读章节。
- 番茄和起点补充匿名公开搜索，并继续保持既有账号书架同步与受限章节边界。

## 后端、兼容性与安全

- 内置书源补齐稳定的站点 ID、能力说明和插件注册信息；插件禁用时在网络请求前阻断搜索、预览和章节抓取。
- 规范化夸克、起点、番茄、拷贝漫画和 COMICORES 的作品链接、搜索结果与错误信息，避免把签名参数、上游会话、Cookie 或原始响应暴露给客户端和日志。
- 数据库初始化会更新可识别的内置书源定义，同时保留用户对插件和书源的启停选择、已导入书籍、阅读进度与其他现有数据。

## 发布验证

- `pubspec.yaml`、Android、Windows 与 FastAPI 共用 `1.7.0+21` 版本源；正式发布标签为 `v1.7.0`。
- 固定 Flutter 3.24.3 下完成 Dart 格式检查、Analyzer 与 123 项 Flutter 测试；Python Ruff、Compileall 与完整 Pytest 套件通过。Pull Request CI 将再次执行这些门禁和跨平台构建检查。
- 正式 Windows ZIP 与签名 Android APK 仅在合并后由 `v1.7.0` 标签工作流构建，并随附 SHA-256 校验文件。

# 升级说明

- V1.7.0 可直接读取 V1.6.0 的 Windows 本机或 Linux 后端数据；升级前仍建议备份数据目录。
- Android 仍只连接 Linux 远程后端，不包含 Python；Windows 仍可在本机后端和 Linux 远程后端之间显式切换。
- COMICORES 仅提供公开元数据预览；夸克只下载明确标记为免费且返回完整正文的章节。
