# 更新内容

## Android 界面修复

- 修复作品详情页标题侵入状态栏、顶部操作区错位，以及部分独立路由未正确处理系统安全区的问题。
- 修复搜索页与书架列表在手机窄屏下的内容裁切、组件溢出和状态反馈布局；Windows 桌面布局保持不变。
- 统一移动端页面表面与轻量动画，移除滚动区域中的高成本模糊效果，并减少滚动期间的重复布局计算。

## 夸克导入

- 夸克目录请求增加限流及 502 / 503 / 504 上游网关错误的有界重试，客户端不再把 HTML 错误页直接显示给用户。
- 导入任务改为通过异步接口轮询完成，补齐任务失败、取消和超时状态，避免客户端把长时间目录抓取误判为导入失败。
- 目录获取统一使用可复用的完整目录请求，并增加短时缓存，避免预览、导入和按需阅读连续重复抓取；仍只处理公开且明确可读的免费章节，不接入登录 Cookie、付费章节或试读回退。

## 阅读流畅度与高刷新率

- 阅读器缓存分页与文本测量结果，减少翻页、字体调整和连续滑动时的重复计算。
- 翻页动画改为轻量位移，正文选择区域与段落渲染减少逐帧重建，改善长章节滚动和分页切换的帧稳定性。
- Android 在系统和设备允许时请求同分辨率下最高不超过 120Hz 的显示模式，并向 Flutter 渲染表面声明高刷新率偏好；实际刷新率仍由设备、系统设置和省电策略决定。

## 发布验证

- `pubspec.yaml`、Android、Windows 与 FastAPI 共用 `1.7.1+22` 版本源；正式发布标签为 `v1.7.1`。
- 固定 Flutter 3.24.3 下执行格式检查、Analyzer、完整 Flutter 测试与 Android Profile 构建；Python Ruff 和完整 Pytest 套件通过。
- 60Hz Android 模拟器完成安装、启动和持续滑动帧耗时抽样；120Hz 真机仍需在支持高刷新率的实体设备上确认系统最终采用的显示模式。

# 升级说明

- V1.7.1 可直接读取 V1.7.0 的 Windows 本机或 Linux 后端数据，不涉及数据库或导入格式迁移。
- Android 仍只连接既有 Linux 远程后端；Windows 客户端界面与本机/远程连接模式保持不变。
