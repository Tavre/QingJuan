# 更新内容

## 手机端书籍简介

- 书籍详情页不再省略超长简介，所有内容保留在固定高度的独立纵向滑动区中。
- Windows 详情页继续完整展示简介；搜索结果列表仍使用有界摘要，避免单个结果占用过多空间。

## 手机端文本输入

- Android 文本输入框关闭长按拖动选区时的放大镜，同时保留系统选区、复制、粘贴和上下文菜单。
- 连接 Token 等密码输入框使用同一交互规则，不会禁用用户主动的标准文本编辑操作。

## 番茄正文获取

- 番茄阅读页返回 HTTP 200 但为空内容、验证页或缺少 `__INITIAL_STATE__` 时，会按既有有界策略重试，不再将无正文响应当作成功。
- 网页 SSR 正文仍不可用时，保留现有番茄 APP 全文回退链，不扩大 Cookie、登录或受保护内容的使用边界。

## 发布与升级

- `pubspec.yaml`、Android、Windows 与 FastAPI 共用 `1.7.3+24` 版本源；正式发布标签为 `v1.7.3`。
- V1.7.3 可直接读取 V1.7.2 的 Windows 本机或 Linux 后端数据，不涉及数据库或导入格式迁移。
- 正式 Release 只在变更合并到 `main` 且全部门禁通过后，由匹配版本的 `v1.7.3` 标签工作流发布并附带 SHA-256。
