# 更新内容

## 小说阅读排版

- 小说段落统一使用稳定的两字首行缩进和两端对齐；短段与自动换行长段的首字保持在同一位置，换行续行与跨页续行不重复缩进。
- 分页、上下滚动和 Windows 阅读器复用同一段落规范化入口，先清理上游空白，再应用客户端排版规则。
- Android 阅读器打开后自动隐藏顶部时间状态栏，只保留底部导航或手势区；应用内控制层显隐不再改变正文安全区或分页结果。

## 音量键阅读

- 阅读设置中的开关明确为“音量键滑动 / 翻页”：上下滚动模式按约一屏距离移动，左右分页模式切换上一页或下一页。
- 连续阅读到章节边界时，同一次按键会等待相邻章节装入并继续移动；从章首向上时可直接定位到上一章末屏。

## Token 输入

- Android 连接 Token 密码框保留原生选区，并在字段旁增加显式“粘贴”按钮，解决部分系统长按菜单无法粘贴的问题。
- 粘贴操作只读取纯文本剪贴板并写入当前输入框，不记录、回显或上传剪贴板内容。

## 发布与升级

- `pubspec.yaml`、Android、Windows 与 FastAPI 共用 `1.7.4+25` 版本源；正式发布标签为 `v1.7.4`。
- V1.7.4 可直接读取 V1.7.3 的 Windows 本机或 Linux 后端数据，不涉及数据库或导入格式迁移。
- 正式 Release 只在变更合并到 `main` 且全部门禁通过后，由匹配版本的 `v1.7.4` 标签工作流发布并附带 SHA-256。
