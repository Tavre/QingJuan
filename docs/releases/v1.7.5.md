# 更新内容

## 小说阅读排版

- 修复 V1.7.4 在部分 Android 字体下将两字缩进字符参与两端对齐后，短段越短越向右偏移、长段首行与换行续行错位的问题。
- 首行缩进改为严格等于两倍正文字号的布局占位，不再把不可见空白字符交给字体整形；分页、上下滚动和 Windows 阅读器共用同一渲染入口。
- 新增实际字形坐标回归测试，覆盖短段首字、长段首字、长段换行左边界和跨页续行，防止测试字体掩盖实机差异。

## 发布与升级

- `pubspec.yaml`、Android、Windows 与 FastAPI 共用 `1.7.5+26` 版本源；正式发布标签为 `v1.7.5`。
- V1.7.5 可直接覆盖安装 V1.7.4，不涉及后端数据、书籍、阅读进度或设置迁移。
- 正式 Release 只在变更合并到 `main` 且全部门禁通过后，由匹配版本的 `v1.7.5` 标签工作流发布并附带 SHA-256。
