# 青卷 V1.7.6

## 跨设备小说排版

- 修复连续阅读和 Windows 阅读器只限制正文 `maxWidth`、导致短段按固有宽度收缩后被单独居中的问题。
- 每个小说正文项强制占满同一阅读栏；短段与自动换行长段的首字使用相同页面全局横坐标，不再依赖小米、OPPO 等设备字体的宽度与换行结果。
- 两字首行占位随系统文字缩放同步变化，换行续行和跨页续行仍从正文左边界开始。

## Android 顶部沉浸

- V1.7.5 的状态栏原生代码确实已进入发布 APK；本版修复部分 OEM 在窗口重新获焦后覆盖一次性隐藏状态的问题。
- 阅读器在窗口获焦、应用恢复和配色变化后重新隐藏顶部状态栏，并以当前阅读背景色覆盖状态栏、Decor 和刘海短边区域，避免露出黑色窗口底色。
- 底部系统导航或手势区继续保留；退出阅读器和进入听书时恢复宿主窗口状态。

## 兼容性

- V1.7.6 可直接覆盖安装 V1.7.5，不涉及后端数据、书籍、阅读进度或设置迁移。
