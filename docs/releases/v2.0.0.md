# 青卷 V2.0.0

## Windows 本机模型设置

- Windows 本机模式可直接在客户端“设置 → 翻译服务”中维护翻译模型、API 密钥、视觉能力、系统提示词和外部 OCR，不再跳转浏览器管理界面。
- 本机后端关闭 `/admin` 管理站点，只接受受信回环客户端通过业务 API 保存模型设置；模型与 OCR 密钥不写入客户端偏好，也不从后端回显。
- Linux 远程模式继续由管理界面维护模型配置；Android 与 Windows 远程客户端仍只读取脱敏状态和触发后端自检。

## 阅读分页

- 分页阅读改为按真实字体、文字缩放、行距、首屏标题和页脚高度测量内容，避免估算字符数导致页尾文字被截断或溢出。
- 分页优先在换行和中文标点处断开，并为极端窗口尺寸与无障碍文字缩放保留稳定前进和缓存失效逻辑。

## 安全、测试与版本

- 设置保存显式保留或替换既有密钥，并防止客户端回传 Bika 密码等不应暴露的凭据；Windows 发布冒烟测试验证管理站点关闭和本机设置 API 可用。
- 补充 Flutter、FastAPI 与 Windows 本机后端测试，并同步架构、界面、后端和质量规范。
- 应用版本更新为 `2.0.0+29`，正式发布标签为 `v2.0.0`。

## 兼容性

- V2.0.0 可直接覆盖安装 V1.7.7，不涉及后端数据、书籍、阅读进度或设置迁移。
