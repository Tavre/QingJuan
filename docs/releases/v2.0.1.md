# 青卷 V2.0.1 更新日志

V2.0.1 新增“笔趣阁”聚合搜索引擎，并把既有 `biqvge_book` 解析能力以内嵌方式接入青卷后端；运行时无需启动独立解析服务或依赖开发机目录。

## 笔趣阁搜索与导入

- 搜索页新增“笔趣阁”选项，可聚合八零小说网、笔趣阁 5200 与笔趣看结果。
- 搜索结果保留实际提供站点名称，加入书架时统一使用内置笔趣阁书源并按需下载。
- 支持作品元数据、上游可取得的目录和公开章节正文解析，章节链接统一规范化为对应站点的可信地址。
- txt80 支持搜索与分页正文；b520、blqukan 支持公开目录索引与镜像页面解析。

## 稳定性与安全

- 单个上游站点失败或超时不会阻断其他站点的聚合结果，并增加短时结果、目录和失败冷却缓存。
- 限制重定向、封面和章节请求只能访问插件声明的站点域名，拒绝跨站跳转和非受信地址。
- 清理脚本、重复章节、多层 HTML 实体及正文开头的 BOM；空正文、风控页或不兼容页面会明确失败，不伪造章节内容。

## 版本

- 应用版本：`2.0.1+33`；预期发布标签：`v2.0.1`。
